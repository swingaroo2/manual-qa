# Bug Report: BUG-0002

**Title:** Any text entry in last name field overwrites first name field with a single character at a time

**Severity:** critical
**Priority:** high
**Status:** new
**Reported by:** me
**Date:** 2026-06-27

## Environment

- Application and version: Saucedemo current prod version
- Browser and version: Mozilla Firefox 152.0.3
- Operating system: Ubuntu 24.04.4 LTS

## Steps to Reproduce

1. Login with `problem_user`
2. Add one item to cart
3. Navigate to Your Information
4. Type text into Last Name field

## Expected Result

The Last Name field populates with text

## Actual Result

Text typed into the Last Name field replaces the entire text entered into the First Name, only one character at a time entering into the First Name field. Last Name field remains empty, blocking checkout.
